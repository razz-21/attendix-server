# Attendix Server

## Prerequisites

- Node.js installed
- npm installed

Install dependencies:

```bash
npm install
```

## Run the app

For local development without Vercel authentication:

```bash
npm run dev
```

For Vercel-authenticated users who want Vercel local emulation:

```bash
vercel dev
```

Open:

```bash
http://localhost:3000
```

## Build and deploy with Vercel

```bash
vercel build
vercel deploy
```
